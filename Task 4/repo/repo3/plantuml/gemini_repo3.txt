' Relationships

' Python Layer Interactions
ZSwagApp ..> WebFramework : extends/uses
ZSwagApp --> ZSwagGen : uses for schema gen
ZSwagGen --> ZSwagDoc : extracts docs
ZSwagGen --> ZSwagReflect : reflects types
ZSwagApp --> PyModule : imports

' Binding Layer Interactions
PyModule *-- PyOAClient : exposes
PyOAClient --> OAClient : wraps C++ implementation
PyOAClient ..> Zserio : handles blob data

' C++ Core Interactions
OAClient --> OAConfig : reads spec
OAClient --> AuthReg : manages security
OAClient --> OAParser : parses YAML/JSON spec
OAClient --> OAInterface : implements
OAClient --> IHttpClient : sends requests

' HTTP Foundation Interactions
IHttpClient --> HttpSettings : configured by
IHttpClient --> URIUtils : parses URLs
AuthReg --> HttpSecurity : uses signatures/tokens
HttpSecurity --> IHttpClient : signs requests

' Cross-Boundary/External Interactions
OAInterface ..> Zserio : serializes/deserializes data
IHttpClient ..> ExtServer : HTTP/1.1 requests
