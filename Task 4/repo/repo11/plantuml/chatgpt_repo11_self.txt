' === Primary entrypoints observed in code
User --> Platform : direct calls (platform ABI)
User --> CommitProxy : commit calls (forwarded)
User --> TournamentProxy : tournament calls (forwarded)

Owner --> System : configure versions/contracts/types/\nlibrary-name mapping/method metadata
Owner --> Platform : owner-only administration\n(blacklist, token upgrade,\nwithdraw tokens, ownership transfer)

' === Forwarding & dispatch flows (dominant)
CommitProxy -down-|> Forwarder
TournamentProxy -down-|> Forwarder

Forwarder --> System : getContract(version,"MatryxPlatform")
Forwarder --> Platform : forward calldata\n(+ injected sender/version parameters)

Platform --> System : getVersion(), getLibraryName(msg.sender),\ngetContract(version, libName),\ngetContractMethod(version, libName, selector)
Platform --> LibPlatform : delegatecall (selected by System mapping)
Platform --> LibCommit : delegatecall (selected by System mapping)
Platform --> LibTournament : delegatecall (selected by System mapping)

' === Domain-level interactions evidenced via imports/calls
LibPlatform --> System : getVersion(), setContractType()\n(register deployed tournament proxy type)
LibPlatform --> TournamentProxy : deploy new MatryxTournament(version, system)

LibPlatform --> TokenIfaces : transferFrom() for tournament bounty funding
LibCommit --> TokenIfaces : transferFrom()/transfer()\n(commit staking/rewards)
LibTournament --> TokenIfaces : transferFrom()/transfer()\n(entry fees, payouts, withdrawals)

' === Shared utilities
LibPlatform ..> LibGlobals
LibCommit ..> LibGlobals
LibTournament ..> LibGlobals
LibPlatform ..> SafeMath
LibCommit ..> SafeMath
LibTournament ..> SafeMath

' === Access control usage (coarse)
System ..> Ownable
Platform ..> Ownable

SetupGen --> System : generate/execute\naddContractMethod(s)\nfor library dispatch metadata
GasParser --> Ganache : subscribe/read tx receipts\n(JsonRpc provider)
Utils --> Ganache : connect & drive flows
Utils --> Platform : call platform/proxies via ABIs
