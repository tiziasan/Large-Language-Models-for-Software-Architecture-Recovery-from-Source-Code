# Supplemental Material README

This supplemental material is organized as follows.

## Prompts

The **Prompts** folder contains a file collecting all prompts used in the study across the four tasks.

## Task 1

The **Task 1** folder is structured into three subfolders:

* **code**: contains one subfolder for each analyzed sample, named `T1_sample_X`. Each of these subfolders includes the ground truth file, the code snippet provided as input to the LLM, and the PlantUML files generated as output, both in textual format and already rendered as PNG images.
* **analysis**: contains the analysis results for Task 1.
* **plot**: contains the Python scripts and the related files used to generate the plots reported in the paper.

## Task 2

The **Task 2** folder is structured into three subfolders:

* **code**: contains the source code of the different samples provided as input to the LLM.
* **analysis**: contains an Excel file reporting, for each sample, the ground truth alongside the LLM responses for both architectural patterns and design patterns.
* **plot**: contains the Python scripts and the related files used to generate the plots reported in the paper.

## Task 3

The **Task 3** folder is structured into three subfolders:

* **code**: contains the source code of the different samples provided as input to the LLM.
* **analysis**: contains the Excel file reporting, for each sample, the ground truth alongside the LLM responses with the identified architectural styles.
* **plot**: contains the Python scripts and the related files used to generate the plots reported in the paper.

## Task 4

The **Task 4** folder is structured into three subfolders:

* **repo**: contains one subfolder for each code sample, named `repo_X`. Each of these subfolders includes the flattened repository file produced with RepoMix and provided as input to the LLM, the ground truth diagram, and the PlantUML diagrams generated by Gemini and ChatGPT, both in textual format and as PNG images.
* **analysis**: contains the analysis results and the table with the dimensions and values used for the evaluation.
* **plot**: contains the Python scripts and the related files used to generate the plots reported in the paper.
* **repo_github_link.xlsx**: reports the links to the GitHub repositories analyzed in the study for Task 4.
